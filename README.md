# cine_backlog

Protótipo de aplicação mobile para backlog de filmes ainda em desenvolvimento. 

## Stack
- Typescript 6
- Expo Go (SDK 58)

# Rodando o projeto

Clone o repositório do projeto
```bash
git clone https://github.com/jvpaz/cine_backlog.git
```

## Exemplo de `.env` 
Preencha o seu .env seguindo os exemplos

```env
EXPO_PUBLIC_GEMINI_API_KEY='api-key-aqui'
EXPO_PUBLIC_TMDB_API_KEY='api-key-aqui'
```

## Rodando
Instale as dependências necessárias.
```bash
npm install
```
Inicie o projeto.
```bash
npx expo start
```
